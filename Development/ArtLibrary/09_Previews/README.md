# 独立素材预览

人物差异检查：[person-family-preview.html](person-family-preview.html)。四个通用母样提供大图、48/72/96px画布缩略、灰度和纯色/棋盘底切换。原母样比例已认可，新三张仍为外观/体型候选；浏览器视觉交互未验证，不替代游戏中的实际显示。

双击[village-grid-preview.html](village-grid-preview.html)可在本机浏览器查看；无需安装依赖、联网或修改Unity工程。

它以真实独立PNG摆放5栋共用住宅、厨房、农田、固定酒馆和1个人物母样，使用固定斜向轴。可开关网格/占地提示/标签，点击对象调整同类图片大小与图内地面锚点，并导出本地校准JSON。

本工具不是游戏或存档编辑器。布局、比例和地面锚点是工作值；Tavern框不定义建造规则，人物母样不代表实际Person身份，多向/动作尚未制作。导出JSON不属于正式配置链，不能复制到生成Mirror冒充运行配置。
